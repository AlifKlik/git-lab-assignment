3\. How Git helps in real projects



Git is very useful in real-world software development because it allows multiple developers to work on the same project simultaneously without overwriting each other’s work. By using branches, developers can work on new features or fixes independently and then merge them into the main project safely. Git also keeps a history of all changes, making it easy to track progress, revert mistakes, and collaborate efficiently.
